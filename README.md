# BART-Project
BART Data Analysis
Analyzes 2016-2017 BART ridership data from Kaggle. Answers key questions about busiest stations, routes, and peak times.

Quick Start
--
git clone <repo-url>
pip install pandas numpy matplotlib seaborn
notebook bart-project.ipynb
--

Key Insights
- Busiest stations: Top 10 visualized

- Least popular route: WSPR → SBRN (40 passengers)

- Late night rides: 2M+ passengers
